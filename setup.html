Zero-Config Mobile Setup

CLIFrontend for Android

Quick setup guide for connecting the Android app to the Termux bridge.

1 Install Android App

Download and install the release APK on your phone.

⬇️ Download CLIFrontend.apk
2 Start Bridge in Termux

Tap Copy Command below, switch to Termux, and paste it. It automatically downloads missing tools, auto-discovers your files anywhere on your phone, and starts the background bridge.

pkg install -y python curl 2>/dev/null; curl -sL https://raw.githubusercontent.com/adamikoo/frontendcli/main/bridge/start.sh -o ~/start.sh && bash ~/start.sh
🚀 Open Termux
  • ✓ Works from any directory on any Android device
  • ✓ Self-healing: automatically finds or downloads server.py
  • ✓ Acquires wake-lock so Android won't kill it in the background
3 Launch & Use

Open the CLIFrontend app on your phone. You will see ● Connected with full access to your Antigravity agent, terminal, editor, and git changes!

To check bridge status anytime in Termux, run: ~/start.sh status
